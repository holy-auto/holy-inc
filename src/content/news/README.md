# お知らせの投稿手順

このディレクトリに `.md` ファイルを1つ足すだけで、次のすべてに自動で載ります。
**コードを書き換える必要はありません。**

- トップページのお知らせ（新しい順に5件）
- お知らせ一覧 `/news`
- 記事ページ `/news/<ファイル名>`（本文を書いた記事のみ）
- `sitemap.xml`
- RSS `/feed.xml`

## 手順

1. このディレクトリに `<年>-<月>-<内容>.md` を作る（例: `2026-09-new-service.md`）。
   ファイル名がそのまま記事のURLになるので、英小文字とハイフンで書く。
2. 下の書式で中身を書く。
3. コミットしてプッシュする。デプロイされれば公開される。

## 書式

```md
---
date: "2026-09-14"          # 必須。YYYY-MM-DD
category: "サービス"          # 必須。日本語の分類
categoryEn: "Service"       # 必須。英語の分類
title: "〜しました。"         # 必須。日本語の見出し
titleEn: "..."              # 必須。英語の見出し
---

本文（任意）。1行空けた塊が1段落になる。

本文を書くと `/news/<ファイル名>` に記事ページができる。
書かなければ一覧に見出しだけが載る。
```

**本文が無いときに記事ページを作らないのは意図的です。** 見出しだけのページを
量産すると、検索エンジンに中身の薄いページと見なされるためです。

## 気をつけること

- **書いていないことは書かない。** 実績・数値・メディア掲載は、出典を示せるものだけ。
- `date` は実際に起きた日。未来の日付は書かない。
- `category` は既存のもの（会社／サービス／プロダクト／地域貢献）に合わせると
  一覧の見え方が揃う。新しい分類を作ってもよい。

## 書式を間違えたら

`npm run check:links` が落ちて、どのファイルの何が足りないかを教えます。
ビルド（`npm run build`）も同じパーサを通るので、壊れたまま公開されることはありません。
